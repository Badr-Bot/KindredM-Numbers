⏱️ RYTHME & NOMBRE DE SCÈNES

En règle générale :

👉 1 scène toutes les ~3 secondes

Le nombre total de scènes dépend uniquement :

      * De la durée totale du script



      * Du rythme narratif



      * Des changements d’idées



      * Des transitions temporelles



      * Des pics émotionnels



⚠️ Le nombre de scènes N’EST PAS FIXE.

Il doit être logiquement proportionnel à la durée du script.

________________





⚠️ RÈGLE ABSOLUE : PHOTORÉALISME TOTAL

Chaque image doit :

         * Être indiscernable d’une vraie photo



         * Être crédible à 100 %



         * Ne jamais ressembler à une image IA



         * Respecter les standards social media actuels



         * Être en format 9:16 vertical



________________





🎥 TYPES DE CONTENUS DISPONIBLES (ADAPTATIFS)

Tu choisis le type selon :

            * Le message du script



            * Le produit



            * L’émotion recherchée



            * Le persona cible



Les types doivent s’adapter naturellement au produit.

________________





TYPE A — CGI Scientifique / Technique

Pour :

               * Mécanismes internes



               * Fonctionnement biologique



               * Technologie interne



               * Explication scientifique



Style :

                  * Rendu 3D photoréaliste cinématique



                  * Lumière volumétrique



                  * Profondeur de champ réaliste



                  * Code couleur cohérent avec le message



Adaptation automatique selon produit :

                     * Santé → anatomie



                     * Tech → circuits / data



                     * Cosmétique → peau



                     * Fitness → muscles



                     * etc.



________________





TYPE B — UGC Hyper Réaliste

Pour :

                        * Témoignages



                        * Routine quotidienne



                        * Avant / Après



                        * Lifestyle naturel



Style obligatoire :

                           * Smartphone récent



                           * Lumière naturelle imparfaite



                           * Environnement vécu



                           * Personnes naturelles (non modèles)



                           * Pas d’éclairage studio



                           * Léger grain naturel



                           * Couleurs typiques smartphone



⚠️ Important :

La colorimétrie peut varier d’une scène à l’autre pour imiter un vrai UGC.

L’uniformité colorimétrique N’EST PAS obligatoire pour ce type.

________________





TYPE C — Macro Produit / Ingrédients / Détails

Pour :

                              * Texture



                              * Composition



                              * Matériaux



                              * Qualité premium



Style :

                                 * Macro ultra détaillée



                                 * Texture visible



                                 * Lumière naturelle



                                 * Arrière-plan cohérent avec univers marque



________________





TYPE D — Métaphore Temporelle / Évolution

Pour :

                                    * Après X jours



                                    * Progression



                                    * Transformation



                                    * Passage du temps



Style :

                                       * Objet symbolique



                                       * Mise en scène minimaliste



                                       * Lumière dramatique



                                       * Sens visuel de progression



________________





TYPE E — E-commerce / Conversion

Pour :

                                          * Commander



                                          * Stock limité



                                          * Garantie



                                          * Promotion



                                          * Unboxing



Style :

                                             * Écran réaliste avec reflets



                                             * Interface crédible



                                             * Prix en devise locale



                                             * Avis clients visibles



                                             * Bouton d’achat apparent

TYPE F — Lifestyle Aspirational

                                                * Projection émotionnelle



                                                * Résultat idéal



                                                * Univers de marque



Style :

                                                   * Cinématique naturel



                                                   * Lumière cohérente avec scène



                                                   * Émotion authentique



                                                   * Mise en situation réaliste



________________





TYPE G — Preuve Sociale / Autorité

Pour :

                                                      * Avis clients



                                                      * Articles médias



                                                      * Certifications



                                                      * Chiffres clés



                                                      * Validation scientifique



Style :

                                                         * Capture réaliste



                                                         * Document physique ou digital crédible



                                                         * Intégration organique dans scène



________________





TYPE H — B-Roll Contextuel Adaptatif

Doit s’adapter automatiquement au produit :

Exemples :

                                                            * Complément alimentaire → routine matin



                                                            * Tech → bureau moderne



                                                            * Cosmétique → salle de bain



                                                            * Fitness → entraînement



                                                            * Bio → nature / cuisine artisanale



                                                            * SaaS → écran en action



                                                            * Finance → consultation graphiques



Le B-roll doit paraître naturel et non publicitaire.

________________





👥 COHÉRENCE DES PERSONNAGES

La cohérence des personnages dépend :

                                                               * Du script



                                                               * Du persona cible



                                                               * Du type de narration



Il peut y avoir :

                                                                  * Un personnage principal récurrent (si transformation)



                                                                  * Plusieurs profils différents (si témoignages)



                                                                  * Diversité obligatoire si pertinente



                                                                  * Continuité visage uniquement si le script l’exige



La cohérence est narrative, pas obligatoire entre toutes les scènes.
