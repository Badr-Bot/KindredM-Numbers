## Contenu

﻿PROMPT MANUS — GÉNÉRATION SÉQUENTIELLE D’IMAGES PUBLICITAIRES (VERSION UNIVERSELLE)

________________





🎯 OBJECTIF

Ton objectif est de générer toutes les images nécessaires pour une publicité vidéo verticale (9:16).

Produit : [NOM DU PRODUIT]

Catégorie : [TYPE DE PRODUIT]

Positionnement : [PREMIUM / SANTÉ / TECH / COSMÉTIQUE / FITNESS / etc.]

Marché cible : [PAYS / PERSONA]

Je vais te fournir :

* Le script complet



* Les visuels du packaging



* Tous les documents du dossier (branding, études, claims, bénéfices, persona, etc.)



________________





📚 ÉTAPE 1 — ANALYSE OBLIGATOIRE

Avant de commencer :

   1. Lis attentivement le script



   2. Analyse tous les documents du dossier



   3. Identifie :



      * Les bénéfices clés



      * Les mécanismes expliqués



      * Les moments émotionnels



      * Les transitions temporelles



      * Les arguments de conversion



Tu dois intégrer TOUTES les informations importantes du dossier dans les visuels.

________________





⏱️ RYTHME & NOMBRE DE SCÈNES

En règle générale :



⚠️ Les scènes doivent être créées EXCLUSIVEMENT à partir du script ci-joint.

👉 1 scène toutes les ~3 secondes

Le nombre total de scènes dépend :

         * De la durée du script



         * Du rythme narratif



         * Des changements d’idée



         * Des transitions importantes



⚠️ Le nombre de scènes N’EST PAS FIXE.

Il doit être proportionnel à la durée du script (souvent entre 20 et 45 scènes).

________________





⚠️ RÈGLE ABSOLUE : PHOTORÉALISME TOTAL

Chaque image générée doit :

            * Être indiscernable d’une vraie photo



            * Être crédible à 100 %



            * Ne jamais paraître générée par IA



            * Respecter les standards social media actuels



            * Être en format 9:16 vertical



________________





🎥 TYPES DE CONTENUS DISPONIBLES (ADAPTATIFS)

Tu choisis dynamiquement le type selon :

               * Le message du script



               * Le produit



               * L’émotion recherchée



               * Le persona cible



________________





TYPE A — CGI Scientifique / Technique

Pour :

                  * Mécanismes biologiques



                  * Fonctionnement interne



                  * Technologie



                  * Explication scientifique



Style :

                     * 3D photoréaliste cinématique



                     * Lumière volumétrique



                     * Profondeur de champ réaliste



                     * Codes couleur cohérents avec le message



Adaptation automatique selon produit :

                        * Santé → anatomie



                        * Tech → circuits / data



                        * Cosmétique → pénétration cutanée



                        * Fitness → fibres musculaires



                        * etc.



________________





TYPE B — UGC Hyper Réaliste (Priorité Haute)

Pour :

                           * Témoignages



                           * Routine



                           * Transformation



                           * Utilisation produit



                           * Lifestyle naturel



Style obligatoire :

                              * Photo smartphone récente



                              * Lumière naturelle imparfaite



                              * Environnement réel et vécu



                              * Personnes naturelles (non modèles)



                              * Aucune lumière studio



                              * Léger grain naturel



                              * Couleurs typiques smartphone



⚠️ La colorimétrie peut varier d’une scène à l’autre pour renforcer le réalisme UGC.

L’uniformité colorimétrique n’est pas obligatoire.

________________





TYPE C — Macro Produit / Ingrédients / Détails

Pour :

                                 * Texture



                                 * Composition



                                 * Matériaux



                                 * Qualité



Style :

                                    * Macro ultra détaillée



                                    * Texture visible



                                    * Lumière naturelle



                                    * Univers cohérent avec la marque



________________





TYPE D — Métaphore Temporelle / Progression

Pour :

                                       * Après X heures



                                       * Après X jours



                                       * Transformation



                                       * Passage du temps



Style :

                                          * Objet symbolique



                                          * Lumière dramatique



                                          * Composition minimaliste



                                          * Sens visuel d’évolution



________________





TYPE E — E-commerce / Conversion

Pour :

                                             * Commander



                                             * Stock limité



                                             * Promotion



                                             * Garantie



                                             * Unboxing



Style :

                                                * Écran réaliste avec reflets



                                                * Interface crédible



                                                * Prix en devise locale



                                                * Avis clients visibles



                                                * Bouton d’achat apparent



________________





TYPE F — Lifestyle Aspirational

Pour :

                                                   * Projection émotionnelle



                                                   * Résultat idéal



                                                   * Univers de marque



Style :

                                                      * Cinématique naturel



                                                      * Émotion authentique



                                                      * Mise en situation crédible



________________





TYPE G — Preuve Sociale / Autorité

Pour :

                                                         * Avis clients



                                                         * Articles médias



                                                         * Certifications



                                                         * Chiffres clés



Style :

                                                            * Capture réaliste



                                                            * Document crédible



                                                            * Intégration organique



________________





TYPE H — B-Roll Contextuel Adaptatif

S’adapte automatiquement au produit :

Exemples :

                                                               * Complément alimentaire → routine matin



                                                               * Tech → bureau moderne



                                                               * Cosmétique → salle de bain



                                                               * Fitness → entraînement



                                                               * Bio → nature



                                                               * SaaS → écran en action



                                                               * Finance → graphiques



Le B-roll doit sembler naturel et non publicitaire.

________________





👥 COHÉRENCE DES PERSONNAGES

La cohérence dépend :

                                                                  * Du script



                                                                  * Du persona



                                                                  * De la narration



Il peut y avoir :

                                                                     * Un personnage principal récurrent (si transformation)



                                                                     * Plusieurs profils différents (si témoignages)



                                                                     * Diversité si pertinente



                                                                     * Continuité visage uniquement si nécessaire



La cohérence est narrative, pas obligatoire entre toutes les scènes.

________________





🔁 PROCESSUS DE GÉNÉRATION SÉQUENTIEL

Tu dois suivre exactement ce processus :

                                                                        1. Découper le script selon le rythme (~1 scène / 3 secondes).



                                                                        2. Déterminer le nombre total de scènes.



                                                                        3. Commencer par la scène 1.



                                                                        4. Décrire précisément l’image que tu vas générer (type + intention + composition).



                                                                        5. Attendre ma confirmation.



                                                                        6. Générer l’image.



                                                                        7. Passer à la scène suivante.



                                                                        8. Répéter jusqu’à la fin.



________________





📌 FORMAT POUR CHAQUE SCÈNE

Avant génération :

                                                                           * Numéro de scène



                                                                           * Timecode



                                                                           * Type



                                                                           * Objectif émotionnel



                                                                           * Description précise de l’image



Puis attendre validation.
