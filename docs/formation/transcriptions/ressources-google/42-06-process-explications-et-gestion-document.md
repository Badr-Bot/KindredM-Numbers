# 42 — 06 Process: Explications et Gestion (Document)

> **Source : document Google public de la formation**
> Référencé par : BUSINESS OPERATIONS / 06 Process: Explications et Gestion

## Contenu

﻿Process: pourquoi sont-ils indispensables et comment les gérer ?

1. Pourquoi absolument avoir des process

* Sans process, tout dépend des fondateurs.

→ Ils deviennent le goulot d’étranglement et doivent valider ou corriger chaque détail.

* Sans process, l’équipe travaille “à l’instinct”.

→ Résultats instables, erreurs récurrentes, beaucoup de perte de temps.

* Les process permettent d’augmenter la productivité.

→ Moins de questions, moins d’allers-retours, plus de vitesse d’exécution.

* Ce qui n’est pas documenté ne peut pas être amélioré.

→ Impossible d’identifier où sont les blocages, ni de créer une version 2.

→ Impossible de déléguer proprement.

* Il existe deux types de problèmes dans une marque:

→ Problème de personnes.

→ Problème de process.

Si les bonnes personnes suivent les bons process, 80 pour cent des problèmes disparaissent.

2. Les mauvaises habitudes qui bloquent une marque

* Penser “il n’y a que moi qui peux le faire bien”.

* Faire les choses soi-même parce que “ça ira plus vite”.

* Donner des tâches via Loom ou messages random, sans structure.

* Demander des tâches sans expliquer le pourquoi ni l’objectif final.

* Créer des process trop complexes, impossibles à suivre.

* Ne pas documenter, ou documenter sur trop d’outils différents.

* Ne jamais auditer ses process pour vérifier s’ils fonctionnent encore.

→ Résultat: confusion, surcharge mentale, équipe frustrée, fondateur indispensable à chaque étape.

________________





3. Comment savoir ce que vous devez processer

* Regardez toutes les tâches que vous faites dans la semaine:

→ Quelles sont les tâches récurrentes?

→ Quelles sont celles qui reviennent plusieurs fois dans l’année?

→ Quelles sont celles qui génèrent des erreurs régulières?

* Priorité aux process qui:

→ Impactent directement le revenu.

→ Réduisent les erreurs coûteuses.

→ Sont nécessaires à la croissance (media buying, créa, influence).

→ Font gagner du temps dès la première semaine.

Règle simple:

Si une tâche doit être faite plus d’une fois, elle mérite un process.

4. Comment créer un process simple et efficace

Étape 1 — Choisir un seul outil de task management

* Asana, ClickUp, Monday, Notion, peu importe.

* L’important, c’est d’en choisir un et de s’y tenir.

Étape 2 — Définir l’objectif du process

* Exemple: “Uploader une campagne Meta prête à tester”.

* Clarifier ce que ce process doit permettre d’obtenir.

Étape 3 — Lister toutes les étapes nécessaires

* Du point A au point Z, sans sauter d’étape.

* Chaque étape doit être 100 pour cent actionnable.

Étape 4 — Définir les owners

Pour chaque étape:

→ Qui est responsable?

→ Qui valide?

→ Qui exécute?

Étape 5 — Documenter le process

• Mettre la version écrite dans votre outil de management.

• Enregistrer un Loom pour montrer l’exemple en temps réel.

→ Cela permet de former un nouveau collaborateur en quelques minutes.

5. Exemple concret: uploader une campagne Meta avec obj testing

Flow complet

1. Concept créatif



 → Owner: Creative Strategist



→ Étapes:



• Définir la stratégie créative.



• Faire le planning de concepts.



• Valider avec le fondateur, le Performance Manager ou le Senior Media Buyer.



2. Copywriting



 → Owner: Copywriter ou Creative Strategist



→ Étapes:



• Écrire les hooks, body copy, CTA.



• Valider avec Creative Strategist.



3. Production créative



 → Owner: Video Editor ou Static Designer



→ Étapes:



• Monter les vidéos.



• Créer les visuels.



• Respecter les guidelines.



4. Feedback et validation



 → Owner: Creative Strategist



→ Étapes:



• Donner les retours.



• Faire valider la version finale.



5. Préparation pour l’upload



 → Owner: Creative Strategist



→ Étapes:



• Rassembler les assets.



• S’assurer de la cohérence entre copies et créas.



6. Upload et mise en ligne



 → Owner: Media Buyer



→ Étapes:



• Uploader la campagne.



• Configurer audiences, budgets, placements.



• Vérifier que tout correspond aux directives.



Documentation

• Loom enregistré montrant chaque étape.

• Checklist dans l’outil de management.

• Version écrite du process dans la base interne.

6. Conclusion: pourquoi c’est indispensable

• Les process rendent votre marque scalable, prévisible et performante.

• Ils permettent à n’importe quel collaborateur de produire un résultat de qualité.

• Ils réduisent la dépendance au fondateur.

• Ils éliminent 80 pour cent des erreurs et des pertes de temps.

7. Récap rapide

→ Sans process, le fondateur devient indispensable.

→ Avec des process simples, l’équipe devient autonome.

→ Ce qui est documenté peut être amélioré.

→ Ce qui est clair peut être délégué.

→ Ce qui est délégué peut être optimisé.
