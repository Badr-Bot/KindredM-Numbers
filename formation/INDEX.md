# Index des leçons — Formation MASTER

Codes de citation : `MB-xx` = module Media-Buying, leçon xx. Les skills Claude
utilisent ces codes pour sourcer chaque affirmation.

Statuts : `vide` (fichier créé, rien dedans) · `brut` (transcription collée,
note à faire) · `note` (note rédigée par Claude, à relire) · `ok` (relue et
validée par Badr — seul statut sur lequel on décide d'un budget).

Les leçons prioritaires ont déjà leurs deux fichiers créés : il n'y a plus qu'à
coller le verbatim dans la colonne « Transcription ».

## Autres modules

À créer quand tu les attaques. Convention de code : deux ou trois lettres
majuscules qui rappellent le module (`CR` pour créa, `OF` pour offre, `BE` pour
back-end), puis le numéro de leçon. Ajoute le module ici **et** dans
`.claude/skills/formation-master/SKILL.md` (section « Corpus ») pour que les
skills sachent qu'il existe.

## Ordre de priorité pour remplir

Tu n'as pas besoin des 15 leçons pour que ça serve. Dans l'ordre de rendement,
vu que tu tournes déjà du budget sur NIVA :

1. **MB-07 à MB-10** (les protocoles par palier) — c'est le cœur opérationnel,
   ce qui rend le skill `protocole-scaling` réellement utilisable.
2. **MB-12** (algorithme) — donne le *pourquoi*, améliore toutes les autres
   réponses.
3. **MB-11 et MB-14** (santé du compte, erreurs) — la base du skill `audit-compte`.
4. **MB-02 à MB-04** (tester & master) — la partie test créa.
5. Le reste au fil de l'eau.
