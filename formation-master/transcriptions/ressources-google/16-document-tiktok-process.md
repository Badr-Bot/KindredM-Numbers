STRATEGIE DE TESTING Si pas de meta :





1. Campagne ABO -> 1 produit = 1 campagne

2. 10+ vidéos différentes minimum (hooks, formats, musiques)

3. Full Broad

4. Budget test : 150 à 200EUR/jour

5. Objectif : CPA < BE en 24-48h





KPI à suivre :

- CTR > 1.2 %

- CPM < 8EUR

1. Dupliquer la créa gagnante (nouvelle musique, outro, format)

2. Passer en Smart+ ou CBO (toujours en broad)

3. Activer Cost Cap dès que tu veux stabiliser les résultats

Quick Wins TikTok Ads – à appliquer directement





* Exclure ceux qui ont vu moins de 3 sec pour éviter de payer deux fois les non qualifiés.

* Dupliquer une créa performante en changeant juste la musique ou les sous-titres.

* Lien musique ici les sons : https://ads.tiktok.com/business/creativecenter/inspiration/popular/music/pc/en top du pays qu’on cible +last 7DAYS

* Le hook doit capter en moins de 1,5 sec. Sinon, Remake un meilleur Hook.

* Tester une version full texte avec fond produit.

* Utiliser Spark Ads pour profiter de l’engagement social natif.

* Séparer les audiences broad 18-34 et 35+ pour analyser les perfs.

* Nettoyer les commentaires (supprimer les négatifs, épingler les bons).

* Fin de vidéo = call-to-action dynamique ou urgence visuelle.

* Les UGC simples filmés à l’iPhone marchent mieux que les vidéos pro.

* Utiliser les POP cards

* Refresh metadata https://www.adarsus.com/en/remove-metadata-online-document-image-video

* Rafraîchir les créas toutes les semaines

Campaign Optimization rules setup

1. If yesterday ROAS >~ benchmark ROAS (BE ROAS + 20% margin); scale budget 20% (vertical scaling).

2. If yesterday ROAS ~ BE ROAS; Do Nothing

3. If yesterday ROAS < BE ROAS: Reduce 20%

4. If last 3 days + today ROAS ~/< BE ROAS; reduce budget 20% (stabilize).

5. If last 7 days + today ROAS < BE ROAS; turn off the ad sets (kill losers).





Adset Optimization rules setup
