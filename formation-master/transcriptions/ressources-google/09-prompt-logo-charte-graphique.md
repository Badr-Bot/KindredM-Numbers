# 09 — Prompt logo + charte graphique

> **Source : document Google public de la formation**
> Référencé par : 0 to 1 : MASTER ONE / 51 Logo IA (Canva), Charte Couleur, Trust Badges

## Contenu

﻿Prompt 1 (Logo + Charte Graphique + Badge)





(Les parties entre crochets [ ] sont à remplacer)





Tu es un Brand Designer senior spécialisé en marques premium e-commerce dans le secteur [NICHE : ex. wellness / café / skincare / complément alimentaire / mode minimaliste].

________________





⚠️ CONTEXTE OBLIGATOIRE :

Tu dois STRICTEMENT te baser sur tous les documents présents dans le dossier ci-joint.

Ce dossier contient :

* Les informations produit



* Le positionnement



* La cible



* Les bénéfices clés



* La différenciation



* La recherche concurrentielle



Tu dois utiliser ces informations pour orienter les décisions créatives.

Tu ne dois rien inventer hors du dossier.

________________





OBJECTIF :

Créer une charte graphique simple mais stratégique pour [NOM DE LA MARQUE] comprenant :

   1. Typographie du logo



   2. Colorimétrie principale



   3. Palette secondaire



   4. Système de badges cohérent avec la palette



On ne va PAS créer un brand book complet.

On veut une base solide, cohérente et orientée conversion.

________________





ÉTAPE 1 — BRAINSTORM COLORIMÉTRIE

Commence par analyser le positionnement du produit à partir du dossier.

Ensuite, propose 3 univers colorimétriques différents.

Pour chaque univers :

      * Nom de l’univers



      * Palette principale (4 couleurs avec codes HEX)



      * Ambiance émotionnelle



      * Perception client



      * Avantage conversion



      * Risque éventuel



Ensuite :

Recommande UN univers principal et explique pourquoi il est le plus cohérent stratégiquement.

________________





ÉTAPE 2 — LOGO (WORDMARK PRIORITAIRE)

Créer une direction logo uniquement typographique.

Décrire :

         * Style de police (géométrique, arrondie, humaniste, serif moderne, etc.)



         * Sensation recherchée



         * Pourquoi ce style correspond à la marque



         * Comment il performe en e-commerce



Proposer 2 directions typographiques différentes.

Puis recommander la meilleure.

________________





ÉTAPE 3 — PALETTE FINALE

À partir de l’univers sélectionné, définir :

Palette principale :

            * Couleur fond principal



            * Couleur texte principal



            * Couleur accent (CTA)



            * Couleur secondaire



Palette secondaire :

               * Variations pour sections



               * Couleurs pour statistiques



               * Couleurs pour overlays avis clients



Donner les codes HEX précis.

________________





ÉTAPE 4 — SYSTÈME DE BADGES (ALIGNÉ À LA PALETTE)

Tous les badges doivent être cohérents avec la palette choisie.

Créer les badges suivants (adapter si nécessaire selon le produit) :

                  * Bio



                  * [BÉNÉFICE CLÉ 1]



                  * [BÉNÉFICE CLÉ 2]



                  * [USP PRODUIT]



                  * Best Seller



                  * Offre limitée



                  * Expédié 24/48h



                  * Paiement sécurisé



                  * Satisfait ou remboursé



                  * Nouveau



Pour chaque badge :

                     * Forme (rond, capsule, rectangle arrondi)



                     * Couleur fond



                     * Couleur texte



                     * Avec ou sans contour



                     * Ombre ou non



                     * Quand l’utiliser stratégiquement (Hero, carrousel, bundle, page collection…)



________________





FORMAT DE SORTIE :

                        1. Brainstorm univers



                        2. Recommandation finale



                        3. Direction logo



                        4. Palette finale (avec HEX)



                        5. Badges structurés



Ne donne aucune théorie inutile.

Fournis un système exploitable immédiatement.
