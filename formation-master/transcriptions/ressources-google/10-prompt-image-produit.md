# 10 — Prompt image produit

> **Source : document Google public de la formation**
> Référencé par : 0 to 1 : MASTER ONE / 52 Créer des images produit 100% AI qui convertisse

## Contenu

﻿Prompt  (Image produit / Section)





(Les parties entre crochets [ ] sont à remplacer)

Tu es un Directeur Artistique senior spécialisé en e-commerce premium dans le secteur [NICHE : ex. wellness / skincare / complément alimentaire / food / fitness / beauté / cosmétique / tech lifestyle].

________________





⚠️ CONTEXTE OBLIGATOIRE

Tu dois te baser STRICTEMENT sur tous les documents présents dans le dossier ci-joint.

Ce dossier contient :

* Les bénéfices exacts du produit



* Les statistiques validées



* Les arguments différenciants



* Les objections clients



* Le positionnement stratégique



* La cible précise (persona détaillé)



Tu dois exploiter exclusivement ces données.

________________





❌ INTERDICTIONS ABSOLUES

   * Ne rien inventer hors dossier



   * Aucune statistique approximative



   * Aucune promesse non validée



   * Aucun bénéfice non mentionné



   * Aucun chiffre non présent dans les documents



   * Aucun texte ajouté qui ne provient pas du dossier



Chaque texte intégré dans les images doit provenir du dossier.

________________





🎯 OBJECTIF GLOBAL

Créer toutes les images nécessaires à la landing page de [NOM DE LA MARQUE].

Les visuels doivent :

      * Vendre même si le texte n’est pas lu



      * Être compréhensibles en moins de 2 secondes



      * Être optimisés conversion e-commerce



      * Être cohérents entre eux



      * Être exploitables pour :



         * Landing page



         * Carrousel produit



         * Publicités Meta Ads



________________





⚠️ ORDRE STRATÉGIQUE OBLIGATOIRE

Respecter STRICTEMENT cet ordre :

            1. Image produit simple



            2. Image proposition de valeur globale



            3. Image bénéfice unique fort



            4. Image preuve sociale intégrée



            5. Image statistique forte



            6. Image différenciation produit (ingrédients / technologie / formulation / méthode…)



            7. Image mosaïque preuve sociale massive



Ne jamais modifier cet ordre.

________________





🎨 DIRECTION ARTISTIQUE

Tu dois impérativement reprendre :

               * La colorimétrie du produit fourni



               * La typographie présente sur le packaging



               * Le style visuel global



               * L’ambiance émotionnelle



               * Le logo et sa cohérence graphique



Toutes les images doivent s’aligner parfaitement sur l’univers visuel du produit.

Le fond peut être adapté si nécessaire, mais toujours en cohérence avec la marque.

Aucune rupture de style autorisée.

________________





👤 ALIGNEMENT STRICT AU PERSONA CIBLE

Toutes les personnes visibles doivent correspondre STRICTEMENT au persona cible défini dans le dossier.

Analyser :

                  * Âge principal



                  * Sexe dominant (si applicable)



                  * Niveau de revenu



                  * Style de vie



                  * Environnement quotidien



                  * Aspirations



                  * Niveau de sophistication



                  * Problème principal



________________





🎯 RÈGLE ABSOLUE

Les visuels ne doivent PAS représenter une diversité générique.

Ils doivent représenter le persona stratégique.

Exemples :

                     * Cible 20–25 ans urbain → appartement moderne, énergie dynamique



                     * Cible 35–45 ans premium actif → bureau élégant, cuisine minimaliste



                     * Cible jeune parent → maison réelle, ambiance chaleureuse



                     * Cible sportif → salle de sport, posture dynamique



On ne mélange jamais des personas incompatibles.

________________





🖼 SPÉCIFICATIONS PAR IMAGE

________________





🖼 IMAGE 1 — PRODUIT SIMPLE

🎯 Objectif : Identification immédiate + crédibilité

Composition :

                        * Produit centré



                        * Mise en situation minimale



                        * Texture visible si pertinente



                        * Lumière naturelle



                        * Fond cohérent marque



Texte minimal :

                           * Nom marque



                           * Catégorie produit



                           * Signature courte validée dossier



                           * Badge discret si présent dans le dossier



________________





🖼 IMAGE 2 — PROPOSITION DE VALEUR GLOBALE

🎯 Objectif : Résumer toute la promesse

Composition :

                              * Produit ou usage au centre



                              * 4 à 6 icônes autour



                              * Structure symétrique



Texte :

                                 * Titre principal validé dossier



                                 * Bénéfices strictement issus des documents



________________





🖼 IMAGE 3 — BÉNÉFICE UNIQUE FORT

🎯 Objectif : Mettre en avant le différenciateur principal

Composition :

                                    * Lifestyle lumineux



                                    * Persona cible utilisant le produit



                                    * Focalisation émotionnelle



Texte :

                                       * Titre impact (2 lignes max)



                                       * Sous-texte court issu du dossier



________________





🖼 IMAGE 4 — PREUVE SOCIALE

🎯 Objectif : Rassurer immédiatement

Composition :

                                          * Persona réel aligné cible



                                          * Produit visible



                                          * Overlay discret



Texte :

                                             * Avis client réel (si fourni)



                                             * Chiffres validés uniquement



________________





🖼 IMAGE 5 — STATISTIQUE FORTE

🎯 Objectif : Autorité rationnelle

Composition :

                                                * Fond minimal



                                                * 2 à 3 blocs chiffres ou graphiques simples



Texte :

                                                   * Données strictement présentes dans le dossier



________________





🖼 IMAGE 6 — DIFFÉRENCIATION PRODUIT

🎯 Objectif : Montrer ce qui rend le produit unique

Composition :

                                                      * Produit centré



                                                      * Éléments différenciants autour



                                                      * Structure pédagogique claire



Texte :

                                                         * Strictement conforme au dossier



________________





🖼 IMAGE 7 — MOSAÏQUE PREUVE SOCIALE MASSIVE

🎯 Objectif stratégique :

Créer une sensation d’adoption massive et de normalisation sociale immédiate.

________________





🖼 Composition :

                                                            * 8 à 12 photos naturelles



                                                            * Variations réalistes du même persona



                                                            * Différents contextes de vie cohérents avec la cible



                                                            * Effet collage organique type Instagram



                                                            * Pas d’alignement parfait



                                                            * Rendu naturel et spontané



________________





🎥 Style obligatoire :

                                                               * Ultra réaliste



                                                               * Lumière naturelle



                                                               * Pas de lumière studio



                                                               * Qualité smartphone moderne



                                                               * Légères imperfections autorisées



________________





⭐ Overlay central :

                                                                  * 5⭐



                                                                  * Chiffres validés dossier uniquement



Exemples (uniquement si présents dans le dossier) :

                                                                     * +[X] clients satisfaits



                                                                     * Noté [X]/5 par nos clients



Overlay léger, cohérent avec la palette marque.

________________





🧠 OBJECTIF PSYCHOLOGIQUE GLOBAL

Chaque image doit contribuer à :

                                                                        * Réduction du risque



                                                                        * Identification persona



                                                                        * Autorité



                                                                        * Désir



                                                                        * Projection



                                                                        * Normalisation sociale



________________

Tu dois produire :

                                                                           * Les visuels structurés



                                                                           * Les textes exacts à intégrer



                                                                           * Les instructions précises de composition



                                                                           * Les éléments graphiques nécessaires



                                                                           * Les déclinaisons adaptées pour :



                                                                              * Landing page



                                                                              * Carrousel produit



                                                                              * Publicités Meta Ads



Ne donne pas uniquement des descriptions vagues.

Produis un système exploitable immédiatement.
